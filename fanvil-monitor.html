Fanvil IP Phone Monitor

PythonNetworkingSIPMonitoring

Built a desktop monitoring tool that checks the health of the hotel's Fanvil IP phones in one view. For each room it reports network reachability, web login, SIP line registration, call log and overall status, so faulty phones are found before guests report them.

It scans around 220 phones in parallel with a configurable number of workers, refreshes automatically on a set interval, and highlights offline phones, SIP issues, busy (503) responses and login failures. Summary counters show totals at a glance, and problem rows are colored red.

Features include a "show problems only" filter, search by room or IP, a log viewer and Excel export for reporting. It turned a slow manual check of every room into a scan that takes about two minutes.
